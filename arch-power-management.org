* INTRODUCTION
This document outlines the tailored power-saving configurations for your specific laptop fleet running Arch Linux. 
Because your devices feature structurally different architectures, they require completely separate background management daemons.

** Summary Strategy Matrix
| Device | Processor / Graphics | Primary Power Daemon | Special Optimization |
|--------+----------------------+----------------------+----------------------|
| *ThinkPad X13* | AMD Ryzen / Radeon | =power-profiles-daemon= | Native =amd-pstate=, custom udev rule |
| *ThinkPad X280* | Intel Kaby Lake / iGPU | =TLP= | ACPI Thresholds, =intel-undervolt= |
| *MacBook Pro 15"* | Intel Haswell/Broadwell | =TLP= | OS Spoofing, =mbpfan=, =intel-undervolt= |

* SECTION 1: THE AMD THINKPAD X13
Modern AMD Ryzen platforms perform optimally when the Linux kernel manages core scaling autonomously. Do *NOT* install TLP on this machine, as it directly conflicts with the native AMD power drivers.

** 1.1 Swap TLP for Power-Profiles-Daemon
Disable any active TLP services and install the native platform management tool:
#+BEGIN_SRC bash
sudo systemctl disable --now tlp.service
sudo pacman -S power-profiles-daemon
sudo systemctl enable --now power-profiles-daemon
#+END_SRC

** 1.2 Enforce Active AMD P-State Driver
Verify your kernel is utilizing the correct energy-performance preference engine:
#+BEGIN_SRC bash
cat /sys/devices/system/cpu/amd_pstate/status
#+END_SRC
*Expected Output:* =active=.  /Note: If it outputs 'guided' or
'disabled', append =amd_pstate=active= to your kernel command line
flags in your bootloader config, then rebuild it./

** 1.3 Automated Profile Switching (udev rule)
Because =power-profiles-daemon= does not shift profiles on power supply changes by default, deploy this custom rule.
Create file: =/etc/udev/rules.d/99-power-profiles.rules=
#+BEGIN_SRC udev :tangle /sudo::/etc/udev/rules.d/99-power-profiles.rules
# Switch to power-saver mode when the charger is unplugged
SUBSYSTEM=="power_supply", ATTR{online}=="0", RUN+="/usr/bin/powerprofilesctl set power-saver"

# Switch to balanced mode when the charger is plugged in
SUBSYSTEM=="power_supply", ATTR{online}=="1", RUN+="/usr/bin/powerprofilesctl set balanced"
#+END_SRC

Reload rules immediately:
#+BEGIN_SRC bash
sudo udevadm control --reload-rules && sudo udevadm trigger
#+END_SRC

** 1.4 Setting Battery Charge Thresholds via Sysfs
To protect battery health without TLP, manage the limits natively via a dedicated systemd service.
Create file: =/etc/systemd/system/battery-threshold.service=
#+BEGIN_SRC ini
[Unit]
Description=Set Battery Charge Threshold
After=multi-user.target

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/bin/sh -c 'echo 80 > /sys/class/power_supply/BAT0/charge_control_end_threshold'

[Install]
WantedBy=multi-user.target
#+END_SRC

Enable the service:
#+BEGIN_SRC bash
sudo systemctl daemon-reload
sudo systemctl enable --now battery-threshold.service
#+END_SRC

** 1.5 Radeon Graphic Hardware Acceleration
Prevent software video rendering loops from exhausting battery life during media playback:
#+BEGIN_SRC bash
sudo pacman -S libva-mesa-driver mesa-vdpau libva-utils
#+END_SRC
/Verification Command:/ =vainfo=

* SECTION 2: THE INTEL THINKPAD X280
The Intel 8th-generation platform relies heavily on aggressive link states and runtime power management driven by TLP.

** 2.1 Core Installation
#+BEGIN_SRC bash
sudo systemctl disable --now power-profiles-daemon
sudo pacman -S tlp tlp-rdw powertop intel-undervolt
#+END_SRC

** 2.2 TLP Optimized Infrastructure Profile
Modify your configuration inside =/etc/tlp.conf= to align with the following variables:
#+BEGIN_SRC ini
# Battery Care - Enforce safe threshold limits
START_CHARGE_THRESH_BAT0=75
STOP_CHARGE_THRESH_BAT0=80

# CPU Scaling Governors & Hints
CPU_SCALING_GOVERNOR_ON_AC=performance
CPU_SCALING_GOVERNOR_ON_BAT=powersave

CPU_ENERGY_PERF_POLICY_ON_AC=performance
CPU_ENERGY_PERF_POLICY_ON_BAT=power

# PCIe Aggressive Link Management
PCIE_ASPM_ON_AC=default
PCIE_ASPM_ON_BAT=powersupersave

# Intel GPU Caps
INTEL_GPU_MIN_FREQ_ON_BAT=0
INTEL_GPU_MAX_FREQ_ON_BAT=300
INTEL_GPU_BOOST_FREQ_ON_BAT=300
#+END_SRC

Enable and apply changes:
#+BEGIN_SRC bash
sudo systemctl enable --now tlp.service
#+END_SRC

** 2.3 Hardware Undervolting
The Kaby Lake-R architecture responds exceptionally well to small voltage drops, yielding drastically lower operating temperatures and lower idle usage.
Configure file: =/etc/intel-undervolt.conf=
#+BEGIN_SRC ini
undervolt 0 'CPU' -80
undervolt 1 'GPU' -50
undervolt 2 'CPU Cache' -80
#+END_SRC

Apply and persist the changes:
#+BEGIN_SRC bash
sudo intel-undervolt apply
sudo systemctl enable --now intel-undervolt
#+END_SRC

* SECTION 3: THE 2015 MACBOOK PRO 15"
Due to proprietary Apple EFI characteristics, specific kernel level parameters and hardware spoofing rules must be met to drop Intel Haswell/Broadwell CPUs into modern deep C-states.

** 3.1 Unlocking Deep CPU C-States via OS Spoofing
Apple's firmware alters native ACPI tables if it detects a non-macOS boot environment, capping battery efficiency. Trick the system using an AUR module:
#+BEGIN_SRC bash
yay -S apple_set_os-loader
#+END_SRC
This exposes the native hardware layout identically to macOS, letting the CPU cleanly transition to low-draw =C6/C7= sleep cycles.

** 3.2 Tailored Fan Curves
The standard Linux kernel thermal loop triggers excessive fan bursts on older MacBooks. Install =mbpfan= to handle them efficiently:
#+BEGIN_SRC bash
sudo pacman -S mbpfan
sudo systemctl enable --now mbpfan
#+END_SRC

** 3.3 Mitigating Retina Backlight Draw
The 15" Retina panel demands massive power at high resolutions. Enable **Intel Framebuffer Compression** by appending the following argument directly to your bootloader configuration parameter line:
#+BEGIN_SRC text
i915.enable_fbc=1
#+END_SRC

** 3.4 Hardware Undervolting & Base Daemon
Apply the same TLP config details from *Section 2.2*. For undervolting older 4th/5th generation Intel cores, match the file parameters below:
Configure file: =/etc/intel-undervolt.conf=
#+BEGIN_SRC ini
undervolt 0 'CPU' -75
undervolt 1 'GPU' -40
undervolt 2 'CPU Cache' -75
#+END_SRC

Apply rules:
#+BEGIN_SRC bash
sudo intel-undervolt apply
sudo systemctl enable --now intel-undervolt
#+END_SRC

* SECTION 4: REAL-TIME AUDITING
On any of the three systems, disconnect the charger, let the machine idle for 60 seconds, and run:
#+BEGIN_SRC bash
sudo powertop
#+END_SRC
Navigate to the **Overview** tab to trace live power draw:
- *X280 Target:* 3.5W - 5.5W
- *X13 Target:* 4.0W - 6.0W
- *MacBook Pro Target:* 7.0W - 9.5W (higher idle expected due to Retina display architecture)
